CHAPTER 1: INTRODUCTION

1.1 Overview

This project is about building LifeQuest, a gamified productivity and time-management web application. The main aim is to turn boring daily tasks, study sessions, and personal goals into an engaging role-playing game (RPG) where users can level up their real-life skills.

Most traditional to-do apps only show a plain checklist. LifeQuest motivates students by rewarding them with Experience Points (XP) every time they complete a task.

Through this website:

  • Custom Skill System: Users can create, edit, activate, or delete any skills they want (such as Coding, DSA, Fitness, Focus, or Music) instead of being locked into fixed subjects.
  • Dynamic Polygon Radar: A visual skill chart automatically adjusts its shape based on how many skills the user has (2-axis bar, triangle for 3 skills, square for 4, pentagon for 5, hexagon for 6, octagon for 8, etc.).
  • XP & Level Progression: Completing daily tasks awards XP, helping users level up their profile and advance their skill ranks.
  • Streak Tracking with Rest Days: Keeps track of consecutive productive days with intelligent passive decay (resets to 0 if days are missed without valid rest days), while allowing a maximum of 3 planned rest days per calendar week so students stay consistent without fear of accidental streak loss during exams or illness.
  • Stopwatch & Time Tracking: Has a built-in timer to track planned vs. actual time spent on each task.
  • Theme Customization: Users can switch easily between Cyber-RPG Dark Mode and Modern Clean Light Mode.
  • Admin Dashboard: Admins have a special dashboard to monitor user activity, platform statistics, and manage accounts.

We are using React (with Vite), Tailwind CSS, FastAPI (Python), SQLAlchemy, and MySQL (with seamless SQLite fallback) to make the application fast, responsive, and secure. This project will help students stay consistent, build healthy study habits, and track their personal growth.

1.2 Literature Survey

Before designing LifeQuest, we studied several existing productivity and habit-tracking tools:

  • Habitica: Uses retro 8-bit game elements for habits, but forces users into fixed fantasy classes (Warrior, Mage) and punishes missed days harshly by reducing health.
  • Forest: A focus timer that grows virtual trees during study sessions, but does not offer long-term skill levels or task management.
  • Todoist & Notion: Very popular and flexible for managing lists, but they are plain text tools with no gamification, rewards, or visual skill progression.
  • LeetCode & GitHub: Use streaks, badges, and activity heatmaps that strongly motivate developers to practice coding every day.

Gap Identified: There is no single platform that combines customizable skills, dynamic polygon charts, XP leveling, rest-day streak protection, and time-tracking stopwatch in one simple web dashboard for students. LifeQuest is designed to fill this exact gap.

CHAPTER 2: PROBLEM IDENTIFICATION & SCOPE

2.1 Problem Domain

In daily student life, maintaining consistency in studies and personal development is difficult. Some of the main problems we see are:

  • Lack of Motivation: Standard to-do lists give no immediate reward or visual satisfaction when a task is finished.
  • Fixed & Rigid Categories: Most apps force users to use fixed skill names. A student who only wants to track DSA and Fitness cannot adapt the app to their needs.
  • Streak Loss Frustration: If a student is sick or takes a planned Sunday off, other apps reset their streak to zero. This demotivates students and causes them to quit.
  • No Time Difference Tracking: Students struggle to estimate how long a task will take and have no simple way to compare planned time versus actual time spent.
  • Scattered Historical Data: When users edit or delete old tasks, their past achievement history often gets lost or messed up.
  • No Central Admin View: Teachers or club mentors have no way to see overall student activity or manage user accounts.

2.2 Solution Domain

To solve these problems, we developed the LifeQuest Web Application as an all-in-one gamified productivity hub.

Our solution provides:

  • Fully Customizable Skills: Users can add, rename, toggle, or delete any number of skills with custom colors and icons.
  • Dynamic Polygon Visualization: Recharts-powered radar chart that adapts cleanly to N active skills (triangle, square, pentagon, hexagon, octagon).
  • XP & Leveling System: Completing tasks awards instant XP with celebratory confetti animations and rank upgrades.
  • Streak Protection with Rest Days: Users can mark legitimate rest days (up to 3 days per week) so their hard-earned streaks remain safe, backed by intelligent streak decay.
  • Integrated Task Stopwatch: Tracks real execution time and saves the difference between planned and actual duration.
  • Permanent XP History: Even if a task or skill is deleted later, past earned XP and completion dates remain permanently saved in the database.
  • Admin Control Panel: Dedicated admin page to view total users, completed tasks, system hours, and manage user roles.
  • Dark & Light Mode: Beautiful toggle for late-night study sessions or clean daytime reading.

This solution makes daily productivity fun, prevents burnout, and gives students a clear, visual picture of their personal growth over time.

CHAPTER 3: SOFTWARE ENGINEERING APPROACH

3.1 Software Model Used

We are following the Agile Iterative Development Model for this project.

3.1.1 Description

Agile is an iterative model where the project is divided and developed in small steps called sprints. In each sprint, a specific module is designed, coded, and tested. After getting feedback, improvements are made before moving to the next module. This allowed us to build a working prototype quickly and continuously add new features like custom skills and the admin dashboard.

3.1.2 Reason for Use

  • Modular Development: The app has clear separate parts (Auth, Tasks, Gamification, Radar Chart, Admin Panel) that fit naturally into sprints.
  • Flexible to Changes: We could easily upgrade the fixed hexagon into a dynamic polygon without rewriting the backend.
  • Continuous Testing: Each module was tested with automated test scripts before building the next feature.
  • Safe Database Migrations: Allowed us to add new database columns without losing any existing student data.

3.2 Platform Specification

3.2.1 Hardware Specification

  • Processor: Intel Core i3 / AMD Ryzen 3 or above
  • RAM: 4 GB minimum (8 GB recommended)
  • Storage: 10 GB free hard disk space
  • Supported Devices: Laptops, Desktops, Tablets, and Smartphones
  • Internet: Required for cloud sync and package installation

3.2.2 Software Specifications

  • Frontend: React 18, Vite, Tailwind CSS, Recharts (for dynamic polygons), Lucide React (icons)
  • Backend: Python 3.11+, FastAPI (high-performance REST API), Uvicorn (ASGI server)
  • Database: MySQL (primary relational database) & SQLite (local fallback) with SQLAlchemy ORM
  • Authentication: JWT (JSON Web Tokens) with Bcrypt password hashing
  • Operating System: Windows 10 / 11 / Linux
  • Development Tools: VS Code, Git & GitHub, Postman, Chrome DevTools

CHAPTER 4: EXPECTED OUTCOME

By the end of this project, the LifeQuest platform delivers a complete, user-friendly, and responsive web application.

The main expected outcomes are:

  • Gamified Habit Building: Students stay motivated to complete daily tasks by earning XP, leveling up, and celebrating with visual rewards.
  • Personalized Skill Tracking: Every user can define their own learning roadmap (e.g., Coding, Aptitude, Fitness) and view their balance on an auto-adjusting polygon radar.
  • Burnout-Free Streaks: Daily consistency is encouraged without fear, thanks to rest-day protection that prevents accidental streak resets.
  • Accurate Time Estimation: Students learn how much time they actually spend on tasks by comparing estimated minutes with the built-in stopwatch.
  • Secure User & Admin Management: Users can register and log in securely with encrypted passwords, while admins can view platform telemetry and manage users.
  • Polished User Experience: Fast loading times, smooth animations, and a seamless Dark/Light theme toggle make the app pleasant to use daily on both mobile and PC.
